* Convenios del libro que la narración debe respetar

** Sistemas, vectores y matrices

- Sistema :: lista *ordenada* de objetos. Se escribe entre corchetes con
  punto y coma tras cada elemento: $[1;\ 2;\ 1;]$. No es un conjunto
  (los conjuntos van entre llaves y no tienen orden).
- Vector de $\R[n]$ :: sistema de $n$ números reales. Se escribe entre
  *paréntesis*. En horizontal lleva coma tras cada elemento:
  $(\pi,\ -1,\ 0,)$. En vertical, =pmatrix=. *Un mismo vector puede
  escribirse en horizontal o en vertical*: en el libro NO existen
  "vectores fila" ni "vectores columna". Ojo: $(2,)$ es un vector de
  $\R[1]$; $(2)$ es un número.
- Escalar :: número real. "Escalar un vector" = multiplicarlo por un
  número (cambiarlo de escala). Al vector $\lambda\Vect{b}$ se le llama
  *múltiplo* de $\Vect{b}$.
- Igualdad de vectores :: componente a componente: $x_i=y_i$ para $i=1:n$.
- $n:m$ :: la secuencia $n, n+1, \dots, m$ ("notación pythonesca").
- Matriz de $\R[m\times n]$ :: sistema de $n$ vectores de $\R[m]$. Se
  escribe entre *corchetes*; cada vector del sistema se escribe en
  vertical y es una *columna*. $[\Vect{x}]$ es una matriz con una sola
  columna (*matriz columna*), distinta del vector $\Vect{x}$.
- Orden de una matriz :: "$m$ por $n$" (primero filas). Una matriz
  "de orden $n$" (sin más) es cuadrada.
- Igualdad de matrices :: columna a columna.

** El operador selector "$\getItem$" (la idea central de la notación)

- $\eleVR{a}{i}$ ($\Vect{a}\getItem i$) selecciona la componente
  $i$-ésima de $\Vect{a}$: equivale a $a_i$.
- Por la *derecha* de una matriz selecciona una *columna*:
  $\VectC{A}{j}$ (vector de $\R[m]$). Por la *izquierda* selecciona una
  *fila*: $\VectF{A}{i}$ (vector de $\R[n]$). Con los dos a la vez,
  una componente: $\eleM{A}{i}{j}=a_{ij}$.
- Desde 1.4.4 también se admite por la izquierda de un vector:
  $\eleVL{a}{i}=\eleVR{a}{i}=a_i$, y los escalares por la derecha:
  $\lambda\Vect{b}=\Vect{b}\lambda$.
- Apéndice 1.A: con una lista de índices selecciona un subvector:
  $\elemR{\Vect{b}}{(3,3,1)}$.

** Definiciones de las operaciones (siempre "componente a componente")

- Suma :: $\elemR{(\Vect{a}+\Vect{b})}{i}=\eleVR{a}{i}+\eleVR{b}{i}$,
  para $i=1:n$. El selector es *distributivo* respecto de la suma.
- Producto por un escalar :: $\elemRp{\lambda\Vect{b}}{i}=\lambda\eleVRpE{b}{i}$.
  El selector es *asociativo* respecto del producto por escalares
  ("el paréntesis se desplaza", por eso se puede omitir y escribir
  $\lambda\eleVR{b}{i}$).
- Operador lineal :: distributivo respecto de la suma y asociativo
  respecto del producto por escalares. *El selector es lineal*. Más
  adelante: la transposición también es lineal, y el selector de
  filas también.
- Vector nulo $\Vect{0}$ (todas las componentes cero; los nulos de
  $\R[2]$ y $\R[3]$ son distintos). Vector opuesto $-\Vect{a}$:
  $\elemRp{-\Vect{a}}{i}=-\eleVRpE{a}{i}$.
- Matrices (1.5): la suma y el producto por escalar se definen *por
  columnas*: $\elemRp{\Mat{A}+\Mat{B}}{j}=\VectC{A}{j}+\VectC{B}{j}$ y
  $\elemRp{\lambda\Mat{A}}{j}=\lambda\VectCpE{A}{j}$. De ahí se deduce
  que también valen componente a componente y fila a fila.

** Las ocho propiedades (sección 1.2.1, tema del vídeo 5)

Recordatorio de los reales ($a,b,c\in\R$): $a+b=b+a$; $a+(b+c)=(a+b)+c$;
$a+0=a$; $a+(-a)=0$; $ab=ba$; $a(b+c)=ab+ac$; $a(bc)=(ab)c$; $1a=a$.

Para vectores con el mismo número de componentes y escalares $\lambda,\varphi$:
1. $\Vect{a}+\Vect{b}=\Vect{b}+\Vect{a}$
2. $\Vect{a}+(\Vect{b}+\Vect{c})=(\Vect{a}+\Vect{b})+\Vect{c}$
3. $\Vect{0}+\Vect{a}=\Vect{a}$
4. $\Vect{a}+(-\Vect{a})=\Vect{0}$
5. $\lambda(\Vect{a}+\Vect{b})=\lambda\Vect{a}+\lambda\Vect{b}$
6. $(\lambda+\varphi)\Vect{a}=\lambda\Vect{a}+\varphi\Vect{a}$
7. $\lambda(\varphi\Vect{a})=(\lambda\varphi)\Vect{a}$
8. $1\Vect{a}=\Vect{a}$

Son las ocho propiedades que permitirán definir el *espacio vectorial*
$\R[n]$ (Lección de espacios y subespacios). Las mismas ocho valen para
matrices (1.5.1).

El libro enseña *dos estrategias* de demostración:
- Estrategia 1 :: operar con las componentes escritas dentro del vector
  (columnas con $a_1,\dots,a_m$).
- Estrategia 2 :: usar la linealidad del selector y reducir todo a la
  componente $i$-ésima, que es un número real (en el libro los pasos
  que son operaciones entre reales van en azul). Ejemplo (prop. 5):
  $\elemR{\big(\lambda(\Vect{a}+\Vect{b})\big)}{i}
   =\lambda\big(\elemRp{\Vect{a}+\Vect{b}}{i}\big)
   =\lambda\big(\eleVR{a}{i}+\eleVR{b}{i}\big)
   =\lambda\eleVRpE{a}{i}+\lambda\eleVRpE{b}{i}
   =\elemRp{\lambda\Vect{a}}{i}+\elemRp{\lambda\Vect{b}}{i}
   =\elemRp{\lambda\Vect{a}+\lambda\Vect{b}}{i}$.
- En las demostraciones el libro *siempre pone los paréntesis* para
  mostrar qué regla se aplica en cada paso.

** Reglas de reescritura (1.4.4 y 1.6)

- "Distribuir el operador" entre sumandos.
- "Desplazar los paréntesis": $\elemRp{\lambda\Vect{b}}{i}=\lambda\eleVRpE{b}{i}=\eleVLPE{b}{i}\lambda=\elemLp{\Vect{b}\lambda}{i}$.
- "Intercambiar escalar y selector" dentro y fuera del paréntesis.
- Transposición: $\MatT{A}$ tiene por columnas las filas de $\Mat{A}$:
  $\VectTC{A}{i}=\VectF{A}{i}$. Es lineal: $\Transp{\lambda\Mat{A}}=\lambda\MatT{A}$,
  $\Transp{\Mat{A}+\Mat{B}}=\MatT{A}+\MatT{B}$.

** Matrices especiales (1.4.6)

Nula $\Mat{0}$, opuesta $-\Mat{A}$, cuadrada, rectangular, simétrica
($\Mat{A}=\MatT{A}$), diagonal (fuera de la diagonal principal todo
cero; no tiene por qué ser cuadrada), identidad $\Mat{I}$.

** Interpretación que prefiere el libro

Los vectores son *datos* (ejemplo 1.3: tasas de crecimiento del PIB de
cinco países; la posición indica el país) y las matrices son tablas de
datos (columna = año, fila = país). La interpretación geométrica
(flechas) se enseña en los vídeos 3 y 4, pero el libro insiste en que
*lo importante es la definición componente a componente y las reglas de
manipulación simbólica*, no el dibujo.

* Macros de =nacal.sty= (las que necesitan los vídeos)

Sistema de sufijos de las macros (vale para toda la familia =elem*=,
=eleV*=, =VectF/VectC=, =Mat*=, =Trans*=):
- sin sufijo :: el argumento tal cual.
- =p= :: el argumento *dentro* de paréntesis =\big( ... \big)=.
- =P= :: igual, con =\Big( ... \Big)=.
- =E= :: paréntesis *exteriores* (alrededor de toda la expresión).
- =pE= / =PE= :: combinación de ambos.
- versión con =*= :: paréntesis de tamaño normal en vez de =\big=.

* Uso desde Manim

- Preámbulo: todo =Tex=/=MathTex=/=Title= con macros nacal necesita
  =tex_template=myTemplate= donde =myTemplate.add_to_preamble(r"\usepackage{nacal}")=.
  El paquete está instalado en =~/texmf/tex/latex/nacal/nacal.sty=.
- Índices de submobjects: =MathTex(...)[0]= es la cadena, y =[0][k]= el
  glifo k. Cuenta de glifos verificada (idéntica en manim 0.19 y 0.21):
  | Fórmula                                   | Glifos | Reparto                               |
  |-------------------------------------------+--------+---------------------------------------|
  | =\eleVR{a}{i}=                            |      3 | a, \vert, i                           |
  | =\elemRp{\Vect{a}+\Vect{b}}{i}=           |      7 | (, a, +, b, ), \vert, i               |
  | =\elemRp{\lambda\Vect{a}}{i}=             |      6 | (, λ, a, ), \vert, i                  |
  | =\lambda\eleVRpE{a}{i}=                   |      6 | λ, (, a, \vert, i, )                  |
  | =\Vect{a}+\Vect{b} = \Vect{b}+\Vect{a}=   |      7 |                                       |
  | =\begin{pmatrix}1\\ 2\\ 3\end{pmatrix}=   |      7 | (, 1, 2, 3, ) ... los paréntesis grandes ocupan 2 glifos cada uno |
  | =\R[n]=                                   |      2 |                                       |
  | =\eleM{A}{i}{j}=                          |      5 |                                       |
  | =\VectC{A}{j}=                            |      3 |                                       |
  | =\MatT{A}=                                |      2 |                                       |
  Para comprobar índices nuevos: =self.add(index_labels(m[0]))= y
  renderizar un fotograma con =-s=.
- Vectores numéricos: generarlos con el módulo =nacal= y =.latex()=
  (ver abajo) en vez de escribir =pmatrix= a mano.

* Módulo =nacal= de Python (lo que usan los vídeos)

#+begin_src python
import nacal as nc
b = nc.Vector([0, 4, 6])        # vector; .latex() -> \begin{pmatrix}0\\ 4\\ 6\end{pmatrix}
nc.Vector([1, 2, 3], 'h').latex()  # en horizontal: \begin{pmatrix}1,& 2,& 3,\end{pmatrix}
nc.V0(3); nc.V1(3)              # vector nulo y vector de unos
b|3                             # 6   (selector: componente 3)
3*b ; b+b ; -b                  # operaciones; devuelven Vector
nc.fracc(1, 3)                  # Rational(1,3) de sympy, para escalares exactos
B = nc.Matrix([[1,2,3],[0,-1,7]])   # lista de FILAS si se dan listas de números
B = nc.Matrix([a, b, c])        # lista de COLUMNAS si se dan Vectores
1|B ; B|2 ; 2|B|3 ; ~B          # fila 1, columna 2, componente (2,3), transpuesta
nc.Matrix([B|2])                # matriz columna
#+end_src

Precedencia en Python: =*= y =+= se evalúan antes que =|=. Por claridad el
libro recomienda paréntesis siempre: =(3*b)|2=.
