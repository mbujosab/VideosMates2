1. Las propiedades de los números reales, con regla y compás - V05

Vídeo que no sigue ninguna sección del libro: muestra geométricamente (regla y compás) las ocho propiedades algebraicas de los números reales que la Sección 1.2.1 da por conocidas. Tesis: se puede construir todo, pero es incómodo, y de esa incomodidad nacen las reglas de manipulación simbólica (prefacio del libro: "Notation is everything"). El vídeo ilustra, no demuestra; se dice explícitamente.

1.5.3. Escena 2 - La suma, trasladando segmentos

Sobre una recta con el cero y el uno. Un número es un segmento con el origen en el cero y el otro extremo en el número. Sumar es poner (con el compás) el origen del segundo segmento en el extremo del primero: el extremo del segmento trasladado es la suma, es decir, un nuevo segmento con origen en el cero. Conmutativa, asociativa, cero y opuesto (el segmento abatido al otro lado del cero); con la misma regla de la suma, 'a' más su opuesto acaba en el cero, así que no hace falta definir la resta. Durante cada traslación, compas() marca con un punto el origen del segmento que se mueve.

def altura(fila):
    return 1.2 + 0.55*fila

def segmento(desde, hasta, color, fila=0):
    return Line(recta.n2p(desde) + altura(fila)*UP, recta.n2p(hasta) + altura(fila)*UP,
                color=color, stroke_width=10)

def rotulo(seg, texto, color):
    return MathTex(texto, color=color, font_size=42).next_to(seg, UP, buff=0.12)

def compas(seg_origen, valor, desde, fila=0, run_time=1.5, antes=None, abatir=None):
    """Copia el segmento `seg_origen` (de longitud |valor|; su origen es el extremo
    `start`), marca el origen con un punto, levanta la copia en vertical sobre el
    origen, la traslada hasta poner el origen en el punto `desde` y la abate con el
    compás: en el sentido de las agujas del reloj si valor>0, en el contrario si
    valor<0 (el segmento queda orientado como estaba).
    Así se ve desde el principio que el segmento trasladado mide lo mismo y cuál de
    sus extremos es el origen. Devuelve la copia y un grupo con el arco y el punto
    del origen (para borrarlos después).
    Para que el movimiento acompañe a la voz, `antes` y `abatir` son marcas
    (<bookmark mark='x'/>) a las que se espera antes de levantar el segmento y antes
    de abatirlo; deben usarse dentro de un `with self.voiceover(...)`."""
    base = recta.n2p(desde) + altura(fila)*UP
    copia = seg_origen.copy()
    inicio = copia.get_start()
    origen = Dot(inicio, color=copia.get_color(), radius=0.11)
    movil = VGroup(copia, origen)
    hacia_derecha = copia.get_end()[0] > inicio[0]
    if antes is not None:
        self.wait_until_bookmark(antes)
    self.play(FadeIn(origen, scale=2), run_time=run_time/8)
    self.play(Rotate(movil, angle=PI/2 if hacia_derecha else -PI/2, about_point=inicio), run_time=run_time/4)
    self.play(movil.animate.shift(base - inicio), run_time=run_time/4)
    if abatir is not None:
        self.wait_until_bookmark(abatir)
    angulo = -PI/2 if valor > 0 else PI/2
    arco = Arc(radius=abs(valor)*u, start_angle=PI/2, angle=angulo, arc_center=base,
               color=GRAY_B, stroke_width=1.5)
    self.play(Rotate(movil, angle=angulo, about_point=base), Create(arco), run_time=3*run_time/8)
    return copia, VGroup(arco, origen)

def marca(valor, texto, color=COLOR_RESULTADO):
    punto = Dot(recta.n2p(valor), color=color, radius=0.09)
    etq = MathTex(texto, color=color, font_size=42).next_to(punto, DOWN, buff=0.45)
    return VGroup(punto, etq)

def regla(texto):
    return MathTex(texto, font_size=52, color=COLOR_REGLA).next_to(cabecera, DOWN, buff=0.5)

Definición de mi escena con voz

Subclase de VoiceoverScene con pausas de distintas duraciones, el selector de voz, la marca de copyright y un voiceover que convierte los dos puntos de la narración en una pausa (Azure no la hace) y que quita del subtítulo las marcas, los <break> y las comillas simples de entonación ('a') en español, y hace funcionar las marcas <bookmark mark'x'/>= también con gTTS (con Azure la voz da el instante exacto de cada palabra; con gTTS se estima repartiendo la duración). Para sincronizar una animación con una palabra concreta: marca en el texto y self.wait_until_bookmark("x") dentro del with. Su método setup() (que Manim ejecuta antes de construct()) llama a self.voz(), así que las clases de las escenas no tienen que hacerlo. 

class MiEscenaConVoz(VoiceoverScene):
    def setup(self):
        """Manim lo ejecuta antes de construct(): fija la voz del idioma."""
        self.voz()

    def pausa_muy_corta(self, n=0.3):
        self.wait(n)
    def pausa_corta(self, n=0.5):
        self.wait(n)
    def pausa(self, n=1):
        self.wait(n)
    def pausa_media(self, n=1.5):
        self.wait(n)
    def pausa_larga(self, n=3):
        self.wait(n)
    def pausa_muy_larga(self, n=5):
        self.wait(n)

    @contextmanager
    def voiceover(self, text=None, **kwargs):
        """Como VoiceoverScene.voiceover, con tres añadidos: los dos puntos producen
        una pausa en la voz (Azure no la hace por sí sola); el subtítulo conserva el
        texto original (sin las marcas <bookmark mark='x'/>); y con gTTS, que no da
        los tiempos de cada palabra, las marcas se estiman repartiendo la duración
        proporcionalmente al texto, de modo que self.wait_until_bookmark("x")
        funciona con los dos servicios (con Azure, con precisión)."""
        if text is not None:
            # el subtítulo no lleva ni marcas, ni pausas SSML escritas a mano (<break time="600ms"/>),
            # ni las comillas simples que guían la entonación de Azure ('a', 'b más c'); los apóstrofos
            # ingleses (Euclid's) no se tocan porque van pegados a una letra
            subtitulo = re.sub(r"\s*<break[^>]*/>\s*", " ", remove_bookmarks(text))
            subtitulo = re.sub(r"(?<!\w)'([^']{1,15})'(?!\w)", r"\1", subtitulo)
            kwargs.setdefault("subcaption", subtitulo)
            if SERVICIO_VOZ == "gtts":
                text = re.sub(r"\s*<break[^>]*/>\s*", ", ", text).replace(":", ".")
            elif BREAK_DOS_PUNTOS:
                text = text.replace(": ", ": " + BREAK_DOS_PUNTOS)
        with super().voiceover(text=text, **kwargs) as tracker:
            if text is not None and "<bookmark" in text and not getattr(tracker, "bookmark_times", None):
                # gTTS guarda en la caché el texto sin marcas: se reponen y se estiman los tiempos
                tracker.data["input_text"] = text
                tracker.data["word_boundaries"] = tracker._get_fallback_word_boundaries()
                tracker._process_bookmarks()
            yield tracker

    def anuncia_regla(self, nueva, anterior=None, run_time=1):
        """Muestra, atenuada, la fórmula que se va a ilustrar (en lugar de la anterior, si la hay).
        Queda a la vista durante la construcción; al terminar, destaca_regla() la enciende."""
        nueva.set_opacity(0.45)
        if anterior is None:
            self.play(FadeIn(nueva), run_time=run_time)
        else:
            self.play(ReplacementTransform(anterior, nueva), run_time=run_time)
        return nueva

    def destaca_regla(self, regla, run_time=1.5):
        """La ilustración ha terminado: la fórmula pasa a opacidad plena y parpadea."""
        self.play(regla.animate.set_opacity(1), run_time=run_time/3)
        self.play(Indicate(regla, color=COLOR_RESULTADO, scale_factor=1.15), run_time=2*run_time/3)

3.2. Montaje: concatenar las escenas, música de entrada y salida, subtítulos

El vídeo final se monta a partir de los mp4 de las escenas (no de la clase del vídeo completo): corregir una escena no obliga a renderizarlo todo ni a pagar otra vez la voz, y los límites entre escenas quedan exactos. Cada segmento se recodifica igualando la duración del audio y del vídeo (concatenar sin recodificar deja un parón en cada unión, pues manim genera el audio unas décimas más largo que la imagen). La música suena en la portada (volumen volumen) y se funde cuando empieza la primera escena; vuelve al empezar la escena cierre (bajo la voz, con volumen_voz), sube en la última escena (los créditos) y se funde a negro con la imagen. La voz se normaliza con loudnorm y se rellena con silencio hasta la duración total (loudnorm retrasa unos 3 s y, sin el relleno, la mezcla acababa antes que la imagen y la música de los créditos se cortaba en seco). Los .srt de las escenas se desplazan y se funden en un único video.srt junto al mp4 (para subirlo a YouTube).

escenas es la lista ordenada de clases; cierre la escena en la que vuelve la música. El mp4 y el srt finales quedan en la raíz del repositorio del idioma.

import ast, textwrap

arbol = ast.parse(open(f"lib/{fichero}.py", encoding="utf-8").read())
idx   = 0 if idioma == "es" else 1

def texto(nodo):
    try:
        return ast.literal_eval(nodo)
    except Exception:
        return ast.unparse(nodo)

def es_tr(n):
    return (isinstance(n, ast.Call) and isinstance(n.func, ast.Name)
            and n.func.id == "tr" and len(n.args) >= 2)

def es_borrado(stmt):
    return ast.unparse(stmt).startswith("self.play(*[FadeOut(mob) for mob in self.mobjects])")

# Primera clase con construct(): la del vídeo completo.
construct = next(f for c in arbol.body if isinstance(c, ast.ClassDef)
                 for f in c.body if isinstance(f, ast.FunctionDef) and f.name == "construct")

escena, items = 0, []   # la portada es la escena 0
def volcar():
    global items
    if items:
        print(f"==== {'Escena' if idioma == 'es' else 'Scene'} {escena} ====\n")
        for tipo, t in items:
            if tipo == "voz":
                print(textwrap.fill(t, 72), "\n")
            else:
                print(f"    [{t}]\n")
    items = []

for stmt in construct.body:
    if es_borrado(stmt):
        volcar(); escena += 1; continue
    en_voz = set()
    for n in ast.walk(stmt):
        if isinstance(n, ast.Call) and isinstance(n.func, ast.Attribute) and n.func.attr == "voiceover":
            en_voz |= {id(s) for s in ast.walk(n) if es_tr(s)}
    for n in sorted((n for n in ast.walk(stmt) if es_tr(n)), key=lambda n: (n.lineno, n.col_offset)):
        items.append(("voz" if id(n) in en_voz else "pantalla", texto(n.args[idx])))
volcar()
