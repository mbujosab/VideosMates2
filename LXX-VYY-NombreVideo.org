* Cómo funciona esta plantilla (fuente única bilingüe)

Este fichero org genera, mediante =org-babel-tangle= (=C-c C-v t=), *dos*
ficheros de python idénticos salvo por una línea:

- =./lib/LXX_VYY_FileName.py= con ~LANG = "es"~ (vídeo en español).
- =../videoMath2/lib/LXX_VYY_FileName.py= con ~LANG = "en"~ (vídeo en inglés).

Las reglas para que el código sea bilingüe son tres:

1. Toda narración y todo texto que aparezca en pantalla se escribe con
   ~tr("texto en español", "text in English")~. Las fórmulas con
   notación =nacal= son comunes a ambos idiomas y no se traducen.
2. La voz la fija automáticamente =MiEscenaConVoz.setup()= llamando a
   ~self.voz()~, que elige la voz de Azure del idioma (o la de Google
   si la variable de entorno =VOZ= vale =gtts=, útil para pruebas, pues
   Azure cobra por carácter).
4. El bloque [[guion]] extrae la narración de un idioma en prosa para
   revisarla sin leer código.
5. La portada es una escena propia (sobre ella suena la música) y el
   vídeo final se monta con [[montaje]] a partir de los mp4 de las
   escenas: concatenación, música de entrada y salida, normalización de
   la voz, fundido final y un único fichero de subtítulos.
3. Los bloques de la sección [[*Rodando: 1,2,3\dots ¡acción!][Rodando]] reciben el idioma como
   parámetro y se encargan de renderizar en el repositorio que toca.

** Definición de mi escena con voz
  :PROPERTIES:
  :UNNUMBERED: t
  :END:

Subclase de =VoiceoverScene= con pausas de distintas duraciones, el
selector de voz, la marca de copyright y un =voiceover= que convierte
los dos puntos de la narración en una pausa (Azure no la hace) y que
hace funcionar las marcas =<bookmark mark='x'/>= también con gTTS (con
Azure la voz da el instante exacto de cada palabra; con gTTS se estima
repartiendo la duración). Para sincronizar una animación con una palabra
concreta: marca en el texto y =self.wait_until_bookmark("x")= dentro del
=with=. Su método =setup()= (que Manim ejecuta antes de =construct()=)
llama a =self.voz()=, así que las clases de las escenas no tienen que
hacerlo.

#+name: Definición de mi escena con voz
#+BEGIN_SRC python :noweb no-export :eval no
class MiEscenaConVoz(VoiceoverScene):
    def setup(self):
        """Manim lo ejecuta antes de construct(): fija la voz del idioma."""
        self.voz()

    def pausa_muy_corta(self, n=0.3):
        self.wait(n)
    def pausa_corta(self, n=0.5):
        self.wait(n)
    def pausa(self, n=1):
        self.wait(n)
    def pausa_media(self, n=1.5):
        self.wait(n)
    def pausa_larga(self, n=3):
        self.wait(n)
    def pausa_muy_larga(self, n=5):
        self.wait(n)

    @contextmanager
    def voiceover(self, text=None, **kwargs):
        """Como VoiceoverScene.voiceover, con tres añadidos: los dos puntos producen
        una pausa en la voz (Azure no la hace por sí sola); el subtítulo conserva el
        texto original (sin las marcas <bookmark mark='x'/>); y con gTTS, que no da
        los tiempos de cada palabra, las marcas se estiman repartiendo la duración
        proporcionalmente al texto, de modo que self.wait_until_bookmark("x")
        funciona con los dos servicios (con Azure, con precisión)."""
        if text is not None:
            # el subtítulo no lleva ni marcas ni pausas SSML escritas a mano (<break time="200ms"/>)
            kwargs.setdefault("subcaption", re.sub(r"\s*<break[^>]*/>\s*", " ", remove_bookmarks(text)))
            if SERVICIO_VOZ == "gtts":
                text = re.sub(r"\s*<break[^>]*/>\s*", ", ", text).replace(":", ".")
            else:
                text = text.replace(": ", ': <break time="500ms"/> ')
        with super().voiceover(text=text, **kwargs) as tracker:
            if text is not None and "<bookmark" in text and not getattr(tracker, "bookmark_times", None):
                # gTTS guarda en la caché el texto sin marcas: se reponen y se estiman los tiempos
                tracker.data["input_text"] = text
                tracker.data["word_boundaries"] = tracker._get_fallback_word_boundaries()
                tracker._process_bookmarks()
            yield tracker

    def anuncia_regla(self, nueva, anterior=None, run_time=1):
        """Muestra, atenuada, la fórmula que se va a ilustrar (en lugar de la anterior, si la hay).
        Queda a la vista durante la construcción; al terminar, destaca_regla() la enciende."""
        nueva.set_opacity(0.45)
        if anterior is None:
            self.play(FadeIn(nueva), run_time=run_time)
        else:
            self.play(ReplacementTransform(anterior, nueva), run_time=run_time)
        return nueva

    def destaca_regla(self, regla, run_time=1.5):
        """La ilustración ha terminado: la fórmula pasa a opacidad plena y parpadea."""
        self.play(regla.animate.set_opacity(1), run_time=run_time/3)
        self.play(Indicate(regla, color=COLOR_RESULTADO, scale_factor=1.15), run_time=2*run_time/3)

    def voz(self, servicio=SERVICIO_VOZ):
        """Fija el servicio de voz según el idioma del vídeo."""
        if servicio == "gtts":
            self.set_speech_service(GTTSService(lang=LANG, tld="com"))
        else:
            self.set_speech_service(AzureService(voice=VOCES_AZURE[LANG]))

    <<Créditos en distintas partes de la pantalla>>

    <<Pausa para pensar>>
#+END_SRC

        'Análisis de las opciones de eliminación elegidas'
        lista = [100,20,10,4,2,1]
        opcion = set()
        for t in lista:
            if (tipo - (tipo % t)) in lista:
                opcion.add(tipo - (tipo % t))
                tipo = tipo % t
        return opcion

*** Tarjeta de pausa para pensar

Las demostraciones cortas se proponen como ejercicio: la tarjeta invita
a pausar el vídeo, se espera unos segundos y, si se da una pista, se
muestra y se vuelve a invitar a pausar. Misma tarjeta en todos los
vídeos. =pista= es el texto en pantalla (puede llevar LaTeX) y
=pista_voz= lo que dice la voz (por defecto, el mismo texto).

#+name: Pausa para pensar
#+BEGIN_SRC python :eval no
def pausa_para_pensar(self, pista=None, pista_voz=None, segundos=4):
    """Tarjeta que invita a pausar el vídeo; opcionalmente da una pista y vuelve a invitar."""
    def tarjeta(texto):
        barra = lambda: RoundedRectangle(corner_radius=0.06, width=0.2, height=0.6,
                                         fill_color=COLOR_ESCALAR, fill_opacity=1, stroke_width=0)
        icono = VGroup(barra(), barra()).arrange(RIGHT, buff=0.12)
        rotulo = Tex(texto, tex_template=myTemplate, font_size=38)
        rotulo.scale_to_fit_width(min(rotulo.width, config.frame_width*0.75))
        contenido = VGroup(icono, rotulo).arrange(RIGHT, buff=0.4)
        marco = RoundedRectangle(corner_radius=0.25, width=contenido.width+0.8, height=contenido.height+0.6,
                                 stroke_color=COLOR_ESCALAR, fill_color=BLACK, fill_opacity=0.85)
        return VGroup(marco, contenido).to_edge(DOWN, buff=0.4)

    invitacion = tr("Pause el vídeo e inténtelo.", "Pause the video and give it a try.")
    tarjeta1 = tarjeta(invitacion)
    with self.voiceover(text=invitacion) as tracker:
        self.play(FadeIn(tarjeta1), run_time=min(0.8, tracker.duration))
    self.wait(segundos)
    if pista is not None:
        tarjeta2 = tarjeta(tr("Pista: ", "Hint: ") + pista)
        with self.voiceover(text=tr("Una pista: ", "A hint: ") + (pista_voz or pista)) as tracker:
            self.play(ReplacementTransform(tarjeta1, tarjeta2), run_time=min(0.8, tracker.duration))
        tarjeta3 = tarjeta(tr("Pause de nuevo e inténtelo.", "Pause again and try once more."))
        with self.voiceover(text=tr("Pause de nuevo e inténtelo.", "Pause again and try once more.")) as tracker:
            self.play(ReplacementTransform(tarjeta2, tarjeta3), run_time=min(0.8, tracker.duration))
        self.wait(segundos)
        tarjeta1 = tarjeta3
    self.play(FadeOut(tarjeta1), run_time=0.6)

class VectorR2():
    def __init__(self, lista, rpr='c', color=GRAY_B):
        """Inicializa un Vector con una lista"""
        coords = lista + [0] if len(lista)<3 else lista        
        self.color  = color

    def dot(self, ejes, radio=0.08):
        return Dot(ejes.c2p(*self.coords), radius=radio, color=self.color)

    def v_line(self, ejes):
        return ejes.get_vertical_line(ejes.c2p(*self.coords), color=self.color)

    def h_line(self, ejes):
        return ejes.get_horizontal_line(ejes.c2p(*self.coords), color=self.color)

    def arrow(self, ejes):
        return ejes.get_vector(self.Vector.lista, stroke_color = self.color, stroke_width=4)

class VectorR3():
    def __init__(self, lista, rpr='c', color=GRAY_B):
        """Inicializa un Vector con una lista"""
        coords = lista + [0] if len(lista)<3 else lista
        self.color  = color

        self.proyXY = self.coords[:-1] + (0,)
        self.proyZ  = (0,0,) + (self.coords[-1],)

    def dot(self, ejes, radio=0.08):
        return Dot3D(ejes.c2p(*self.coords), radius=radio, color=self.color)

    def x_line(self, ejes):

        return Line3D(start=ejes.c2p(*self.proyZ), end=ejes.c2p(*self.coords), thickness=0.01)

    2023-07-06 Uwe Zimmermann & Abulafia
    2024-03-09 Uwe Zimmermann
    '''
    def __init__(self, filename=None, imageops=None, speed=1.0, loop=False, **kwargs):
        self.filename = filename
        self.imageops = imageops
        self.speed    = speed
        self.loop     = loop
        self._id = id(self)
        self.status = VideoStatus()
        self.status.videoObject = cv2.VideoCapture(filename)

        self.status.videoObject.set(cv2.CAP_PROP_POS_FRAMES, 1)
        ret, frame = self.status.videoObject.read()
        if ret:
            frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)            
            img = Image.fromarray(frame)

            if imageops != None:
                img = imageops(img)
        else:
            img = Image.fromarray(np.uint8([[63, 0, 0, 0],
                                        [0, 127, 0, 0],
                                        [0, 0, 191, 0],
                                        [0, 0, 0, 255]
                                        ]))
        super().__init__(img, **kwargs)
        if ret:
            self.add_updater(self.videoUpdater)

    def videoUpdater(self, mobj, dt):
        if dt == 0:
            return
        status = self.status
        status.time += 1000*dt*mobj.speed
        self.status.videoObject.set(cv2.CAP_PROP_POS_MSEC, status.time)
        ret, frame = self.status.videoObject.read()
        if (ret == False) and self.loop:
            status.time = 0
            self.status.videoObject.set(cv2.CAP_PROP_POS_MSEC, status.time)
            ret, frame = self.status.videoObject.read()
        if ret:
            frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)  # needed here?        
            img = Image.fromarray(frame)

            if mobj.imageops != None:
                img = mobj.imageops(img)
            mobj.pixel_array = change_to_rgba_array(
                np.asarray(img), mobj.pixel_array_dtype
            )

#+BEGIN_SRC python  :results discard

import itertools
def get_sub_indexes(tex):
    ni = VGroup()
    colors = itertools.cycle([RED,TEAL,GREEN,BLUE,PURPLE])
    for i in range(len(tex)):
        n = Text(f"{i}",color=next(colors)).scale(0.7)
        n.next_to(tex[i],DOWN,buff=0.01)
        ni.add(n)
    return ni

** Montaje: concatenar las escenas, música de entrada y salida, subtítulos

El vídeo final se monta a partir de los mp4 de las escenas (no de la
clase del vídeo completo): corregir una escena no obliga a renderizarlo
todo ni a pagar otra vez la voz, y los límites entre escenas quedan
exactos. Cada segmento se recodifica igualando la duración del audio y
del vídeo (concatenar sin recodificar deja un parón en cada unión, pues
manim genera el audio unas décimas más largo que la imagen). La música
suena en la portada (volumen =volumen=) y se funde cuando empieza la
primera escena; vuelve al empezar la escena =cierre= (bajo la voz, con
=volumen_voz=), sube en la última escena (los créditos) y se funde a
negro con la imagen. La voz se normaliza con =loudnorm= y se rellena con silencio hasta la
duración total (=loudnorm= retrasa unos 3 s y, sin el relleno, la mezcla
acababa antes que la imagen y la música de los créditos se cortaba en seco). Los =.srt= de las escenas se desplazan y se
funden en un único =video.srt= junto al mp4 (para subirlo a YouTube).

=escenas= es la lista ordenada de clases; =cierre= la escena en la que
vuelve la música. El mp4 y el srt finales quedan en la raíz del
repositorio del idioma.

#+name: montaje
#+BEGIN_SRC bash :var fichero="LXX_VYY_FileName" :var escenas="LXX_VYY_E00_Portada LXX_VYY_E01_Introduccion LXX_VYY_E02_TemaEscena LXX_VYY_E03_TemaEscena LXX_VYY_E04_TemaEscena LXX_VYY_E05_Resumen ZCreditosFinales" :var cierre="LXX_VYY_E05_Resumen" :var video="LXX_VYY_NombreVideo" :var idioma="es" :var calidad="1080p60" :var musica="music/3Blue1Brown-Zeta-X3.mp3" :var volumen="0.25" :var volumen_voz="0.04" :results output
export LC_ALL=C   # decimales con punto para bc y printf
[ "$idioma" = "en" ] && raiz=../videoMath2 || raiz=.
dir=$raiz/lib/media/videos/$fichero/$calidad
tmp=$raiz/tmp/$video; mkdir -p $tmp; rm -f $tmp/seg_*.mp4

# 1. Un segmento por escena, con audio y vídeo de la misma duración exacta
i=0; lista=""; offsets=""; T=0; T0=""; Tc=""
for esc in $escenas; do
  seg=$(printf "%s/seg_%02d.mp4" $tmp $i)
  dur=$(ffprobe -loglevel error -select_streams v:0 -show_entries stream=duration -of default=nk=1:nw=1 $dir/$esc.mp4)
  fps=$(ffprobe -loglevel error -select_streams v:0 -show_entries stream=r_frame_rate -of default=nk=1:nw=1 $dir/$esc.mp4)
  if ffprobe -loglevel error -select_streams a -show_entries stream=codec_type -of csv=p=0 $dir/$esc.mp4 | grep -q audio; then
    ffmpeg -loglevel error -y -i $dir/$esc.mp4 -af "aresample=48000,apad" -ac 2 -t $dur -r $fps -fps_mode cfr -pix_fmt yuv420p -c:v libx264 -crf 18 -preset fast -c:a aac -b:a 192k $seg
  else
    ffmpeg -loglevel error -y -i $dir/$esc.mp4 -f lavfi -i anullsrc=r=48000:cl=stereo -map 0:v -map 1:a -t $dur -r $fps -fps_mode cfr -pix_fmt yuv420p -c:v libx264 -crf 18 -preset fast -c:a aac -b:a 192k $seg
  fi
  d=$(ffprobe -loglevel error -show_entries format=duration -of default=nk=1:nw=1 $seg)
  offsets="$offsets $T"; [ "$esc" = "$cierre" ] && Tc=$T
  printf "%2d  %-55s %8.3f s  (empieza en %8.3f)\n" $i $esc $d $T
  T=$(bc -l <<< "$T+$d"); [ -z "$T0" ] && T0=$d; dl=$d
  lista="$lista $seg"; i=$((i+1))
done
n=$i; Tl=$(bc -l <<< "$T-$dl"); [ -z "$Tc" ] && Tc=$Tl
printf "Duración total %.3f s; música hasta %.3f s, desde %.3f s (bajo la voz) y desde %.3f s (créditos)\n" $T $T0 $Tc $Tl

# 2. Concatenación recodificada, voz normalizada, música de entrada y salida, fundido final
inputs=""; fc=""; k=0
for seg in $lista; do inputs="$inputs -i $seg"; fc="$fc[$k:v][$k:a]"; k=$((k+1)); done
fin_m1=$(bc -l <<< "$T0+5"); tfade=$(bc -l <<< "$T-6")
dur_m2=$(bc -l <<< "$Tl-$Tc"); ms_m2=$(printf "%.0f" $(bc -l <<< "$Tc*1000")); fade_m2=$(bc -l <<< "$dur_m2-1")
fin_m3=$(bc -l <<< "$T-$Tc"); ms_m3=$(printf "%.0f" $(bc -l <<< "$Tl*1000"))
ffmpeg -loglevel error -y $inputs -i $musica -i $musica -i $musica -filter_complex "
  ${fc}concat=n=$n:v=1:a=1[v0][a0];
  [a0]loudnorm=I=-16:LRA=11:TP=-1.5,apad=whole_dur=$T[voz];
  [$n:a]atrim=0:$fin_m1,volume=$volumen,afade=t=in:st=0:d=1,afade=t=out:st=$T0:d=5[m1];
  [$((n+1)):a]atrim=0:$dur_m2,volume=$volumen_voz,afade=t=in:st=0:d=3,afade=t=out:st=$fade_m2:d=1,adelay=delays=${ms_m2}:all=1[m2];
  [$((n+2)):a]atrim=$dur_m2:$fin_m3,asetpts=PTS-STARTPTS,volume=$volumen,afade=t=in:st=0:d=1,adelay=delays=${ms_m3}:all=1[m3];
  [voz][m1][m2][m3]amix=inputs=4:duration=first:normalize=0[mix];
  [mix]afade=t=out:st=$tfade:d=6[a];
  [v0]fade=t=out:st=$tfade:d=6[v]" \
  -map "[v]" -map "[a]" -c:v libx264 -crf 18 -preset medium -pix_fmt yuv420p -c:a aac -b:a 192k $raiz/$video.mp4
echo "Vídeo: $raiz/$video.mp4"

# 3. Subtítulos: desplazar el srt de cada escena y fundirlos en uno
ESCENAS="$escenas" OFFSETS="$offsets" python3 - "$dir" "$raiz/$video.srt" <<'EOF'
import sys, os, re
dir, salida = sys.argv[1], sys.argv[2]
escenas = os.environ["ESCENAS"].split(); offsets = [float(x) for x in os.environ["OFFSETS"].split()]
def t2s(t):
    h, m, s = t.strip().split(":"); s, ms = s.split(",")
    return int(h)*3600 + int(m)*60 + int(s) + int(ms)/1000
def s2t(x):
    ms = round(x*1000); h, r = divmod(ms, 3600000); m, r = divmod(r, 60000); s, ms = divmod(r, 1000)
    return f"{h:02d}:{m:02d}:{s:02d},{ms:03d}"
k, out = 1, []
for esc, off in zip(escenas, offsets):
    ruta = f"{dir}/{esc}.srt"
    if not os.path.exists(ruta): continue
    for bloque in re.split(r"\n\s*\n", open(ruta, encoding="utf-8").read().strip()):
        lineas = bloque.strip().splitlines()
        if len(lineas) < 3 or "-->" not in lineas[1]: continue
        a, _, b = lineas[1].partition("-->")
        out.append(f"{k}\n{s2t(t2s(a)+off)} --> {s2t(t2s(b)+off)}\n" + "\n".join(lineas[2:])); k += 1
open(salida, "w", encoding="utf-8").write("\n\n".join(out) + "\n")
print(f"Subtítulos: {salida} ({k-1} entradas)")
EOF
#+END_SRC

** Extraer el guion (la narración) para revisarlo

Recorre el fichero de python y saca, escena por escena, los textos
~tr(...)~ del idioma pedido: en prosa la narración (los que están dentro
de ~self.voiceover~) y entre corchetes los textos que aparecen en
pantalla. Sirve para revisar el guion sin leer código y para la
descripción o los subtítulos del vídeo. Como los dos py solo difieren
en =LANG=, lee siempre el fichero español (=./lib/=).

#+name: guion
#+BEGIN_SRC python :python python3 :var fichero="LXX_VYY_FileName" :var idioma="es" :results output
import ast, textwrap

arbol = ast.parse(open(f"lib/{fichero}.py", encoding="utf-8").read())
idx   = 0 if idioma == "es" else 1

def texto(nodo):
    try:
        return ast.literal_eval(nodo)
    except Exception:
        return ast.unparse(nodo)

def es_tr(n):
    return (isinstance(n, ast.Call) and isinstance(n.func, ast.Name)
            and n.func.id == "tr" and len(n.args) >= 2)

def es_borrado(stmt):
    return ast.unparse(stmt).startswith("self.play(*[FadeOut(mob) for mob in self.mobjects])")

# Primera clase con construct(): la del vídeo completo.
construct = next(f for c in arbol.body if isinstance(c, ast.ClassDef)
                 for f in c.body if isinstance(f, ast.FunctionDef) and f.name == "construct")

escena, items = 0, []   # la portada es la escena 0
def volcar():
    global items
    if items:
        print(f"==== {'Escena' if idioma == 'es' else 'Scene'} {escena} ====\n")
        for tipo, t in items:
            if tipo == "voz":
                print(textwrap.fill(t, 72), "\n")
            else:
                print(f"    [{t}]\n")
    items = []

for stmt in construct.body:
    if es_borrado(stmt):
        volcar(); escena += 1; continue
    en_voz = set()
    for n in ast.walk(stmt):
        if isinstance(n, ast.Call) and isinstance(n.func, ast.Attribute) and n.func.attr == "voiceover":
            en_voz |= {id(s) for s in ast.walk(n) if es_tr(s)}
    for n in sorted((n for n in ast.walk(stmt) if es_tr(n)), key=lambda n: (n.lineno, n.col_offset)):
        items.append(("voz" if id(n) in en_voz else "pantalla", texto(n.args[idx])))
volcar()
#+END_SRC
